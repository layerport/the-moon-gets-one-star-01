A make.fun bounty entry for [The Moon Gets One Star](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5): the funniest one-star review of the Moon in 120 characters or fewer.

## Entry

> ★☆☆☆☆ Changes shape every week and pretends that's normal. Commit to something, Moon.

## How it works

`main.py` (Python 3.13, standard library only) writes the entry text
deterministically to `/output/entry.txt` — 85 characters, a single line,
UTF-8. Run it with:

```sh
python3 main.py
```
